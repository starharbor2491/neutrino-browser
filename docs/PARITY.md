# Local capability and acceptance ledger

The target is equivalent local user workflows from Arc, Chrome, Opera GX, Vivaldi and Brave. Split groups into per-workflow acceptance tests before marking them complete. Record tested source/binary and actual outcomes; this table is not a shipped-feature claim. "Implemented" below means the interface and native code exist and the interface is exercised by Rust tests and the interface sandbox; native acceptance on macOS is still required for each row.

| Area | Target | Current boundary |
| --- | --- | --- |
| Navigation | Address/search with suggestions, keyword engines, back/forward lists, zoom per site, find with count, shortcuts, site identity | Implemented: suggestions from tabs/bookmarks/history, custom engines with keywords, long-press back/forward history, per-site zoom memory, find bar with match count, shortcuts that can be changed, reset or removed (standard ones included; a removed menu shortcut still shows in the macOS menu), site information menu, spatial navigation and Fast Forward/Rewind |
| Tabs | Restore/pin/tree/folders/duplicate/reorder/close/reopen, mute, sleep, rename, groups, islands, stacks, previews | Implemented: full tab menu, recently closed list, ⌘1–9 and ⌃Tab, audio indicator, sleeping tabs, archive after N days, AI tab tidying, colored folders, Opera-style islands, Vivaldi-style stacks (drop a tab on a tab to stack), hover previews with page pictures. Folders nest up to four levels, as in Arc (New folder inside, Move folder into). Tiling beyond two panes is not implemented |
| Spaces/windows | Profiles, Spaces with icons and colors, live-page transfer, splits with a divider, saved sessions | Implemented: Space emoji and gradient, delete Space/Profile, icon-only sidebar, resizable split divider and stacked splits, named sessions, moving a tab to a new window (tab menu or dragging it out), Air Traffic Control routing of links from other apps |
| Setup/import | Guided setup that follows the chosen browser, import from installed browsers | Per-browser flows for Arc, Opera GX, Vivaldi, Brave, Chrome and Safari, each with a Modules step; bookmarks and history import from Chrome-family browsers (the profile the browser last used), Firefox and Safari files. Saved passwords import from Chrome, Edge, Brave, Arc, Vivaldi and Opera after macOS asks to use that browser's Keychain key; Firefox and Safari passwords and all cookies are not imported |
| Library | Bookmarks with nested folders/edit/search/reorder, bookmarks bar, history search/day groups/delete, downloads, reading list, boards | Implemented, including nested bookmark folders (`Work/Projects`), drag to reorder, Speed Dial as a bookmark folder with Vivaldi-style groups as its subfolders, Playlist as a reading-list filter and boards with draggable cards. Downloads show progress and can be paused and resumed (WebKit resumes when the site supports it). Boards hold pictures of pages (Add capture). Offline media saving is not implemented |
| Credentials | Local vault, save prompts, autofill, generator, CSV import/export, addresses, cards, passkeys | Keychain vault with a save/update prompt after sign-in (both engines), autofill when one login matches the site, generator and CSV import/export; addresses and payment cards (no security code stored) fill on request, and a bar offers saved cards when a secure page shows a card-number field. Expired cards are refused. Passkeys are not implemented |
| Blocking/privacy | Ad/tracker lists, subscriptions, custom rules, per-site exceptions, HTTPS upgrade, tracking-parameter removal, cookie-banner hiding, site permissions, site data, clear data | Implemented: bundled lists plus subscribed filter lists (EasyList, EasyPrivacy, Peter Lowe's, Fanboy's lists or any https list; domain and `$third-party` rules, and element rules), custom domain and `site##selector` rules, Block an element picker, HTTPS upgrade, parameter removal and de-AMP on top-level navigations in both engines (Google AMP links before loading, and publisher AMP pages that name a canonical article after they load), Chrome's HTTPS-only setting, WebRTC local-address hiding on Chromium, Forget me per site, a site settings list, clearing browsing data by time range (Chromium cookies follow the range; its cache clears for all time), and clearing history, cookies and site data, or cache when Neutrino quits, in every Profile (Chromium's files are removed after the engine stops; bookmarks, extensions and settings stay). Fingerprinting protection (Brave layout default) adds per-site, per-session noise to canvas readouts, reports a generic WebGL renderer and fewer cores; audio and font farbling are not done. URL-pattern network rules and scriptlets are not implemented; phishing protection needs a remote list and is excluded |
| Extensions | Store/local installs, MV3, actions/popups/options/side panels | Chromium's own extension pages, reached from an Extensions button in the Chrome, Brave and GX toolbars (Manage extensions, Chrome Web Store). Extension action buttons, popups and pinning are not implemented |
| Media | Picture in picture, now playing, mute, break mode | Implemented through page scripts in both engines and Chromium's audio mute. A playing page in either engine appears in Now Playing and answers the play/pause keys (Chrome's own media-key handling is turned off so a key acts once) |
| Page tools | Print, PDF, save page, view source, developer tools, capture area/full page/copy, reader styles, page styles, site CSS/JS | Implemented. WebKit full-page capture saves a PDF; Chromium saves a PNG. Reader shows the article's text and up to 12 of its images (fetched without cookies and downsized) and can read aloud with the system voice. Captures can be marked up (pen, highlighter, box, colors, undo) before saving or copying |
| Customization | Hex accent, theme packs, light/dark schedule, wallpaper and live wallpapers, start-page widgets per style, toolbar buttons, panel and status bars, interface CSS, web panels | Implemented. GX and Vivaldi themes set the window's surface and text colors as well as the accent; Customize reorders extra toolbar buttons and removes the built-in Forward, Reload and Bookmark buttons |
| Arc local | Favorites, Peek, Little Arc, Boosts, Easels, Air Traffic Control | Implemented: global Favorites, Peek (shift-click, WebKit tabs), Little Arc for external links, Boosts with CSS, JavaScript, color and Zap, boards for Easels, Air Traffic Control |
| GX | GX Control limits, hot tabs, cleaner, sounds, music, shaders, live wallpapers, panic button | Implemented: the CPU limit first slows background Chromium tabs to a quarter speed (DevTools CPU throttling), then limits put the least recently used background tabs to sleep; network limits apply to Chromium tabs; GX Control panel with limiters, hot tabs and the cleaner; generated sounds and music; page filters as shaders; live wallpapers; panic button; setup's sidebar choices. Fake My History adds productive, learning or wholesome visits to history. RGX and GX Mods packages are not implemented |
| Vivaldi | Panels, web panels, status bar, tab stacks, command chains, page actions, gestures, feeds | Implemented, including mouse gestures (hold Option and drag), spatial navigation, Fast Forward/Rewind, a status bar with zoom slider and tab count, a Feeds panel (RSS and Atom from the publisher, Subscribe from pages that list a feed, unread count on its button, refresh every 30 minutes), Speed Dial groups, and drop-on-tab stacking. Mail and calendar are not implemented |
| Brave | Shields per site, blocked counts, private search start page, Forget me | Implemented, with Brave's sidebar (Bookmarks, Reading List, History) and a start page showing trackers and ads blocked since install and Brave's time-saved estimate. Chromium tabs count blocked requests; WebKit tabs show an estimate from the page's third-party resources on blocked domains |
| Distribution | One offline ARM installer, signing/notarization/trust/payload closure/clean-Mac setup | ARM development DMGs built; installed WebKit copy/launch/quit/removal pass; full Blink, consumer trust and clean-Mac core acceptance pending |

Every feature beyond core browsing (tabs, address bar, find, history, bookmarks, downloads, settings) is a built-in module under `org.neutrino.*` with the `feature` role. Setup has a Modules step in every flow whose defaults follow the browser chosen, and each module can be turned off later in Modules or from the setting it governs.

Before declaring core complete, resolve daily-use gaps, pass native/installed acceptance, verify extensions, and demonstrate protected streaming. Stubs, hidden stock controls, untested logins, and historical receipts do not satisfy gates.

Cloud sync/storage, VPN, crypto wallets, rewards, remote safe-browsing lists and a Neutrino store are excluded. Optional AI services, filter-list downloads from their publishers and extension downloads are allowed.
