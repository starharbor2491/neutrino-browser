# Local capability and acceptance ledger

The target is equivalent local user workflows from Arc, Chrome, Opera GX, Vivaldi and Brave. Split groups into per-workflow acceptance tests before marking them complete. Record tested source/binary and actual outcomes; this table is not a shipped-feature claim. "Implemented" below means the interface and native code exist and the interface is exercised by Rust tests; native acceptance on macOS is still required for each row.

| Area | Target | Current boundary |
| --- | --- | --- |
| Navigation | Address/search with suggestions, keyword engines, back/forward lists, zoom per site, find with count, shortcuts, site identity | Implemented: suggestions from tabs/bookmarks/history, custom engines with keywords, long-press back/forward history, per-site zoom memory, find bar with match count, customizable shortcuts, site information menu. Native acceptance pending |
| Tabs | Restore/pin/tree/folders/duplicate/reorder/close/reopen, mute, sleep, rename, groups, islands, stacks | Implemented: full tab menu (close others/right, copy link, rename, mute, sleep, reset pinned page), recently closed list, ⌘1–9 and ⌃Tab, audio indicator, sleeping tabs with a timer, colored folders, Opera-style islands and Vivaldi-style stacks in the tab strip. Nested folders and tiling beyond two panes are not implemented |
| Spaces/windows | Profiles, Spaces with icons and colors, live-page transfer, splits with a divider, saved sessions | Implemented: Space emoji and gradient, delete Space/Profile, resizable split divider and stacked splits, named sessions. Dragging a tab out into a new window is not implemented |
| Setup/import | Guided setup that follows the chosen browser, import from installed browsers | Per-browser flows for Arc, Opera GX, Vivaldi, Brave and Chrome; bookmarks import from Chrome-family browsers, Firefox and Safari files. History, passwords and cookies are not imported from other browsers |
| Library | Bookmarks with folders/edit/search, bookmarks bar, history search/day groups/delete, downloads, reading list, boards | Implemented, including Speed Dial as a bookmark folder, Playlist as a reading-list filter and boards with draggable cards. Offline media saving is not implemented |
| Credentials | Local vault, generator, CSV import/export, address autofill, passkeys | Keychain vault with fill, generator and CSV import/export; addresses fill on request. Save-on-submit prompts, payment cards and passkeys are not implemented |
| Blocking/privacy | Ad/tracker lists, custom rules, per-site exceptions, HTTPS upgrade, tracking-parameter removal, cookie-banner hiding, site permissions, site data, clear data | Implemented with a bundled list of about 120 domains plus custom domain rules (no cosmetic filters); HTTPS upgrade and parameter removal apply to WebKit navigations and Chrome's HTTPS-only setting; WebKit remembers camera/microphone choices, Chromium uses Chrome's prompts. Phishing protection needs a remote list and is excluded |
| Extensions | Store/local installs, MV3, actions/popups/options/side panels | Unchanged: Chromium's own extension pages. A Neutrino extension toolbar is not implemented |
| Media | Picture in picture, now playing, mute, break mode | Implemented through page scripts in both engines and Chromium's audio mute. Media-key routing relies on each engine |
| Page tools | Print, PDF, save page, view source, developer tools, capture area/full page/copy, reader styles, page styles, site CSS | Implemented. WebKit full-page capture saves a PDF; Chromium saves a PNG |
| Customization | Hex accent, theme packs, light/dark schedule, wallpaper, start-page widgets, toolbar buttons, panel and status bars, interface CSS, web panels | Implemented |
| Arc local | Favorites, Peek, Little Arc, Boosts, Easels | Implemented: global Favorites, Peek (shift-click, WebKit tabs), Little Arc for external links, Boosts as site CSS and hidden elements, boards for Easels. Zapping by pointing at elements is not implemented |
| GX | CPU/RAM/network limits, hot tabs, sounds, music, shaders, panic button | Implemented: limits put background tabs to sleep; network limits apply to Chromium tabs; per-tab resource table; generated interface/keyboard sounds and music; page filters as shaders; panic button. RGX and GX Mods packages are not implemented |
| Vivaldi | Panels, web panels, status bar, tab stacks, command chains, page actions | Implemented. Mouse gestures, mail, calendar and feeds are not implemented |
| Brave | Shields per site, blocked counts, private search start page | Shields per site implemented; per-page blocked counts are not reported by either engine yet |
| Distribution | One offline ARM installer, signing/notarization/trust/payload closure/clean-Mac setup | ARM development DMGs built; installed WebKit copy/launch/quit/removal pass; full Blink, consumer trust and clean-Mac core acceptance pending |

Before declaring core complete, resolve daily-use gaps, pass native/installed acceptance, verify extensions, and demonstrate protected streaming. Stubs, hidden stock controls, untested logins, and historical receipts do not satisfy gates.

Cloud sync/storage, VPN, crypto wallets, rewards, remote safe-browsing lists and a Neutrino store are excluded. Optional AI services and extension downloads are allowed.
